插件安装方法（可选）
  1. 下载 ZIP 并解压，保留解压后的 browser-helper 文件夹。
  2. 在 Chrome 地址栏打开 chrome://extensions，开启“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择含有 manifest.json 的 browser-helper 文件夹。
  4. 刷新本网站，再点击“查询”或“重新检测”，扩展会自动读取并补全结果。

扩展读取 IPSuper、IPHub、IPQualityScore、Scamalytics、IP2Location、GreyNoise、DB-IP、IPRegistry、Blackbox 与 IPQuery 的公开查询页，最多同时打开 3 个临时标签，读完即关闭。网页要求人机验证时，标签会保留最多 150 秒：点下方「去验证」切到该页自己完成，扩展随后自动读取；扩展不会点击或完成验证码。不会把登录 Cookie 发送给服务器。

导入 IPinfo 网页

打开当前 IP 的 IPinfo 详情页 ↗，全选复制页面文字，粘贴后点击导入。

从 IPSuper 补全缺失类型

将「导入类型」拖到书签栏，再打开当前 IP 的 IPSuper 查询。结果完整后点击书签，会在新页面按数据库补全缺失字段。

导入类型 · 打开 IPSuper 查询 ↗
从来源网页补全

查询时会自动尝试来源网页。将「导入来源网页」拖到书签栏；在 IPHub、IPQualityScore、IPData、IPRegistry、DB-IP、Scamalytics、IP2Location、GreyNoise 或 ipapi.is 的目标结果页点击书签，可回传已显示的字段。只补充当前 IP 的缺失字段，同库合并。
